# Adesanmi Adeola Peter — Geospatial Portfolio

Personal portfolio for GIS and remote sensing work, featuring 19 projects, category filters, project details, professional experience, education, contact links and a downloadable CV.

## Run locally

Open `index.html` in a browser, or serve this directory with a static web server. No build step or package installation is required.

## Files

- `index.html`: page structure and profile content
- `style.css`: layout, typography and responsive styles
- `app.js`: project content, filters, dialogs and illustrative artwork
- `CV.docx`: downloadable CV

## Editing

Update the project list in `app.js`, profile text in `index.html`, and appearance in `style.css`. Replace `CV.docx` to update the downloadable CV.

Map illustrations are decorative and explicitly labelled; they are not analytical project outputs. Fonts load from Google Fonts with local fallback fonts.

## Hosting

Deploy these files to a static web host. No backend or environment variables are needed. Email links open the visitor’s email application.
